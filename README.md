# Tiny Bookshop 한국어 패치

Tiny Bookshop (Steam) 비공식 한국어 팬 패치입니다. **게임 버전 1.1.6 기준**으로 제작되었습니다.

---

## 설치 방법

[Releases 페이지](https://github.com/haecam/tiny-bookshop-korean-patch/releases/latest)에서 운영체제에 맞는 파일을 다운로드합니다.

---

### 🪟 Windows

**1. `korean-patch-v1.1.6.zip` 다운로드 후 압축 해제**

**2. 네 개 파일을 아래 경로에 덮어쓰기**

```
C:\Program Files (x86)\Steam\steamapps\common\Tiny Bookshop\
  Tiny Bookshop_Data\StreamingAssets\aa\StandaloneWindows64\
```

> 경로를 찾기 힘든 경우 Steam 라이브러리에서 게임 우클릭 → **로컬 파일 관리**를 선택하면 탐색기 창이 열립니다.  
> 파일 붙여넣기 시 관리자 권한 요청 창이 뜨면 **'계속'** 을 눌러주세요.

**3. Steam → 게임 속성 → 언어 → Polish 선택 후 실행**

> 첫 실행 기준 한국어로 표기되어 있을 수 있습니다.

---

### 🍎 Mac

**1. `TinyBookshop_한국어패치_mac_v0.1.zip` 다운로드 후 압축 해제**

**2. `StandaloneOSX` 폴더 안 파일 6개를 아래 경로에 복사(덮어쓰기)**

Finder에서 **이동 → 폴더로 이동** (`⇧⌘G`) 에 아래 경로를 붙여넣으세요.

```
~/Library/Application Support/Steam/steamapps/common/Tiny Bookshop/Tiny Bookshop.app/Contents/Resources/Data/StreamingAssets/aa/StandaloneOSX
```

> 경로로 바로 연결이 안 되고 게임 실행 아이콘만 뜨는 경우, 아이콘 우클릭 → **패키지 내용 보기**를 선택하면 상세 폴더로 접근할 수 있습니다.

**3. Steam → 게임 속성 → 언어 → Polish 선택 후 실행**

> 첫 실행 기준 한국어로 표기되어 있을 수 있습니다.
